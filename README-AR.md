# موقع أحمد شعبان حسن — Portfolio كامل

نسخة واحدة تضم كل التعديلات المطلوبة حتى الآن. الموقع مبني باستخدام HTML5 وCSS3 وJavaScript نقي، دون Framework أو سيرفر مطلوب لعرض الصفحة.

## محتويات المجلد

```text
interactive-portfolio-complete/
├── index.html                 # الصفحة الرئيسية
├── style.css                  # تصميم الوضع الداكن والفاتح والموبايل
├── script.js                  # الترجمات الأربع، الحركة، الفلاتر، الروابط، النموذج
├── projects/                  # ست صور معاينة تصميمية (ليست مشاريع منفذة)
│   ├── dashboard.webp
│   ├── commerce.webp
│   ├── tasks.webp
│   ├── travel.webp
│   ├── weather.webp
│   └── portfolio.webp
├── certificates/              # أربع صور الشهادات المرسلة
│   ├── mansoura-front-end.jpg
│   ├── bahary-leadership.jpg
│   ├── bahary-workshop.jpg
│   └── bahary-participation.jpg
└── README-AR.md
```

## التشغيل

1. فك الضغط عن ملف ZIP في مجلد جديد.
2. افتح `index.html` في متصفح Chrome. يفضَّل استخدام Live Server داخل VS Code عند العمل والتعديل.
3. **لا تنقل ملفات HTML وCSS وJS وحدها وتترك مجلدَي projects وcertificates**؛ لأن الصور مرتبطة بمساراتهما الحالية.
4. لو ظهرت نسخة مخزنة من الموقع، استخدم `Ctrl + F5`.

## تغيير الصور الستة عندما تنفّذ مشاريعك

افتح `script.js` وابحث عن `const PROJECTS = [` (قريب من أول الملف). كل مشروع يحتوي على اسم ووصف وتقنيات وتصنيف وصورة وروابط.

مثال صورة المعاينة الحالية:

```javascript
image: "projects/dashboard.webp",
demo: "",
code: "",
```

لإضافة مشروع حقيقي:

1. ضع لقطة شاشة من مشروعك داخل مجلد `projects` باسم مثل `my-dashboard.webp` أو `my-dashboard.png`.
2. غيّر الحقل إلى `image: "projects/my-dashboard.webp"`.
3. غيّر `title` و`desc` باللغات الأربع ليتطابقا مع مشروعك الفعلي.
4. أضف رابط النسخة المنشورة في `demo` ورابط GitHub في `code` (مثال `https://github.com/username/repo`).
5. عدّل `categories` و`tags` طبقًا للتقنيات المستخدمة بالفعل.

**تنبيه مهني:** الصور الحالية تصميمات تمثيلية للعرض مؤقتًا ولا تعني أنك أنجزت تلك التطبيقات. لذلك جميع البطاقات موسومة على أنها «معاينة تصميمية / Concept Preview» وروابطها غير نشطة حتى تضع مشاريعك الحقيقية. يفضّل استبدالها قبل إرسال الموقع إلى الشركات.

## وضع الصورة الشخصية والسيرة الذاتية ووسائل التواصل

في أعلى `script.js` ستجد `const CONFIG`، وعدِّل القيم التالية:

```javascript
photo: "profile.jpg",           // ضع الصورة بجوار index.html
cvUrl: "CV.pdf",               // ضع نسخة السيرة الذاتية بجوار index.html
phone: "+20xxxxxxxxxx",      // رقمك الدولي
whatsapp: "+20xxxxxxxxxx",
email: "yourname@example.com",
linkedin: "https://www.linkedin.com/in/your-name/",
github: "https://github.com/your-name",
instagram: "https://www.instagram.com/your-name/",
formEndpoint: ""               // اكتب رابط Formspree لتفعيل الإرسال المباشر
```

في الملفات المسلَّمة القيم فارغة عمدًا؛ فلا نضيف معلومات شخصية أو روابط غير مؤكدة. إذا لم تُضف صورة، تظهر الأحرف `AS` في مكان الصورة.

**النموذج لا يرسل بريدًا من تلقاء نفسه بدون إعداد.** إذا أدخلت بريدك فقط، سيجهز رسالة في تطبيق البريد لدى الزائر، وإذا أدخلت رابط Formspree صحيحًا فسيرسل طلبًا إليه ويعرض نتيجة الإرسال الفعلية.

## التحكم بسرعة الكتابة

في بداية `script.js` مباشرة بعد `CONFIG` تجد `TYPE_SPEED`:

- `greeting`: سرعة كتابة `Hello, I'm`.
- `name`: سرعة كتابة الاسم.
- `role`: سرعة كتابة المسمّى الوظيفي.
- `erase`: سرعة مسح المسمّى.
- `holdRole`: مدة بقاء المسمّى قبل مسحه.

كل القيم بالمللي ثانية؛ الرقم **الأقل يعني أسرع**. وتظهر التحية، ثم الاسم، ثم يتبدل المسمّى بين Front-End Developer وReact Specialist وUI/UX Enthusiast.

- MET — بكالوريوس نظم معلومات عام 2025.
- مشروع التخرج بتقدير **امتياز** (التقدير المذكور يخص المشروع لا إجمالي البكالوريوس).
- دورة جامعة المنصورة في Web Design (Front-End): 48 ساعة، 24 يونيو إلى 14 أغسطس 2024، بتقدير Excellent.
- دورات من MaharaTech في مجال Front-End، دون اختلاق أسماء دورات غير مذكورة.
- شهادات كيان شباب بحري في قسم المشاركات والشهادات منفصلًا عن الدورات التقنية.

الشهادات مصوَّرة من أوراق أصلية مرسلة، ومعروض كل منها للفتح في نافذة مستقلة.

## اللغات والخصائص

- العربية (RTL)، الإنجليزية، الفرنسية، الإسبانية (LTR).
- زر الوضع الداكن والفاتح، مع حفظ اختيار الزائر عبر LocalStorage. الوضع الداكن هو الافتراضي قبل أول تغيير.
- صفحة Responsive، قائمة هاتف، تأثير كتابة، انتقالات تمرير، وفلترة مشاريع حسب التقنية.
- شريط تقدم للتمرير، زر العودة للأعلى، وفحص نموذج الاتصال قبل المحاولة.

## ملحوظات

- الخطوط وبعض أيقونات FontAwesome محمّلة عبر CDN. يمكن عرض الصفحة محليًا، ولكن ظهور هذه الموارد يتطلب اتصالًا بالإنترنت.
- لا تضع كلمة مرور أو API Secret في JavaScript المرسل للمتصفح.
- قبل إرسال رابط Portfolio لشركة، اختبر جميع أزرار Live Demo وGitHub، وضع ملف CV حقيقيًا، واربط نموذج التواصل، واستبدل المشاريع التجريبية بأعمالك.
